# 17. PERFORMANCE REQUIREMENTS

Performance is extremely important.

Optimize the design for:

- Fast initial loading.
- Efficient image loading.
- WebP or AVIF images where available.
- Lazy loading for below-the-fold images.
- Correct image dimensions.
- Minimal JavaScript.
- Minimal CSS complexity.
- No unnecessary animation libraries.
- No autoplay videos.
- No heavy sliders.
- No excessive plugins.

Prioritize Core Web Vitals.

Aim for a Lighthouse Performance score of 90+ on mobile without claiming a score until the website has been tested.
